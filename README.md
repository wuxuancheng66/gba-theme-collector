# 主题构想收集器

用于整理研究选题的轻量协作页面，支持卡片编辑、版本记录、恢复和汇总复制。

## 体验演示

打开 `index.html?demo=1`。演示使用虚构内容，不读取远程数据、不发送网络请求；新增、编辑、删除和恢复只在本页内存生效，刷新即重置。公开作品集应使用此入口。

## 实际协作

默认入口读取目标 GitHub 数据仓库的 `data.json`。公开阅读无需凭据。需要编辑时，点击「连接协作」，填写自己的显示名与仅对目标仓库授权的 GitHub 令牌；令牌只保存在本页内存中，刷新或关闭页面即清除，也可以主动断开。请求固定发送至 `https://api.github.com`，不使用公开共享令牌或编码后的凭据配置文件。

显示名只用于署名，不代表认证；实际读写权限由 GitHub 令牌决定。请使用细粒度、最小权限的令牌，仅为目标数据仓库开放 Contents 读写权限。不要向公开仓库提交真实团队名单、未获同意的构想、访问令牌或配置凭据。

数据格式仍为 `{ "cards": [...] }`，保留原卡片标识、归属、创建和更新时间及最近 20 个历史版本。编辑冲突保留当前输入并提示刷新重试。

## 本机预览

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

浏览器访问 `http://127.0.0.1:8765/index.html?demo=1`。文件直开时，部分浏览器限制剪贴板；复制失败后页面会保留选中的文本供手动复制。

## 验证范围

演示模式应覆盖新增、编辑、历史查看、恢复、导出、刷新重置、键盘关闭与焦点返回。实际协作另需用自己的测试仓库验证授权、并发冲突和同步；不要用生产数据进行破坏性测试。
